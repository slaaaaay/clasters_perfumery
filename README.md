В данном проекте используется датасет, содержащий информацию о парфюмерных ароматах, собранный с сайта Randewoo.
С помощью этих данных планируется провести анализ и сегментацию парфюмов по различным характеристикам.

Цель проекта: Построить модель машинного обучения, которая позволит разделить ароматы на кластеры на основе их числовых характеристик
Это поможет выявить рыночные ниши и сегментировать ассортимент
